# 미사강변고등학교 1학년 4반 영어단어 공부방

수능 빈출 어휘 중 어원이 재미있는 단어를 매일 아침 7시(한국 시간)에 5개씩 공개하는 학급 공부 사이트입니다.

- `words.js` : 단어 은행 (현재 100개 = 20일치, 이후에는 처음부터 다시 반복. 예문은 모두 수능 기출 원문(y: 학년도, src: 독해/듣기)). 같은 형식으로 아래에 추가하면 날짜가 자동으로 이어집니다.
- `app.js` : 날짜 계산, 발음 듣기, 지난 단어, 퀴즈. 시작일은 `START_DATE`.
- 서버 없이 동작하는 정적 사이트라 GitHub Pages에 그대로 올리면 됩니다.
- 테스트: 주소 뒤에 `?date=2026-12-05` 를 붙이면 그날의 화면을 미리 볼 수 있습니다.
